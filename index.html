Github 문제 해결 과정
모두의창업 · 공동대표 겸 Flutter 1명(본인) · BE 1명

공단 근처 직장인이 식당을 찾고, QR로 결제하고, 식권을 쓰는 과정을 앱 하나로 끝내는 서비스입니다. 근로자가 쓰는 고객용 앱과 식당이 쓰는 사장님용 앱으로 나뉩니다.

내가 한 일
  • 공동대표로 기능 범위와 일정을 정하고, 개발 전에 백엔드와 API 규칙(에러 응답, 토큰, 페이지네이션)부터 합의
  • 고객용 앱과 사장님용 앱을 하나의 저장소(Melos)로 묶어 로그인, 네트워크, 공통 UI를 두 앱이 함께 쓰도록 구성
